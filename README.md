## Amulet

A esp32 powered device that acts as a stopwatch and prints out your grades.

### What it should do:
- [ ] Basic functionality as a stopwatch,
	- [ ] Doesnt need a lap button, but still needs a reset and stop button.
	- [ ] preferably Up to seconds, but if can be done more then miliseconds
	- [ ] Maximum 12 hours at least.
- [ ] Grade printing
	- [ ] Decent UI, the color changes for each class and the grades also have a differnet check for 90s, 80s, and 70s.
	- [ ] You don't have to login every time
	- [ ] pull up data from your classes, and find what your current average is at the time
- [ ] Battery powered
	- [ ] 
#### Would preferably add
- [ ] if possible, be able to see the list of your assignments
